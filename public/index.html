    The Unity bridge sends a heartbeat every 5 seconds. An app is marked offline after 20 seconds without one. Sleep, loss of Wi-Fi, or closing the app can cause this. Online confirms server reachability, not multiplayer membership or successful sketch uploads.

      To check the network separately, open that address followed by /api/health in the headset browser. A successful visit appears in the log. This is only a troubleshooting check; normal use does not need the headset browser.

      • No new request when spawning a package: check the bridge reference on the host, Server Url, Unity’s HTTP setting, and the network/firewall. The website cannot see a request that never reaches this server.
      • HTTP 4xx or 5xx: read the error in the log below. The request reached the server but failed.
